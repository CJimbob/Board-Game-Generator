# 王冠之城

一款支持 2–8 人在线房间的秘密选角、城市建造网页桌游。可以邀请朋友加入，也可以添加电脑对手立即开始。

## 已实现

- 四位房间码、跨设备加入和自动同步
- 完整的 2–3 人双角色、4–8 人弃牌与传牌流程
- 27 名角色、七套规则组合，以及 4–7 人可选的 9 号角色
- 54 张基础城区和 30 张独特城区；每局按规则混入 14 张独特城区
- 角色能力、城区能力、金币、抽牌、建造、交换、接管、摧毁与隐藏信息
- 电脑玩家自动选角和行动
- 7/8 城区终局、完整独特城区计分、颜色奖励、完成奖励和同分判定
- 首页与牌桌内随时可打开的完整中文规则书
- 刷新后自动回到当前房间

## 本地运行

```bash
npm install
npm run dev
```

访问 `http://localhost:3000`。

## 验证

```bash
npm test
```

房间状态存储在 Cloudflare D1 中；部署配置位于 `.openai/hosting.json`。
