# 王冠之城

一款支持 2–8 人在线房间的秘密选角、城市建造网页桌游。可以邀请朋友加入，也可以添加电脑对手立即开始。

## 已实现

- 四位房间码、跨设备加入、在线状态与自动同步
- 中英文一键切换；规则书、角色、城区、操作和提示均已双语化
- 10 位恢复码：刷新、断网或换设备后可回到原座位，并自动更换会话凭证
- 房主移交、掉线房主接任、离线玩家电脑托管与真人回归
- 房主可在候场时添加电脑玩家、移除座位和调整房主
- 完整的 2–3 人双角色、4–8 人弃牌与传牌流程
- 27 名角色、七套规则组合，以及 4–7 人可选的 9 号角色
- 54 张基础城区和 30 张独特城区；每局按规则混入 14 张独特城区
- 角色能力、城区能力、金币、抽牌、建造、交换、接管、摧毁与隐藏信息
- 电脑玩家自动选角和行动
- 7/8 城区终局、完整独特城区计分、颜色奖励、完成奖励和同分判定
- 首页与牌桌内随时可打开的完整中英文规则书
- 刷新后自动回到当前房间
- 并发写入保护、请求频率限制，以及 7 天未活动房间自动过期

## 本地运行

```bash
npm install
npm run dev
```

访问 `http://localhost:3000`。

## 验证

```bash
npm test
```

房间状态存储在 Cloudflare D1 中；部署配置位于 `.openai/hosting.json`。恢复码只以摘要形式保存在服务器端，应像密码一样妥善保管。
