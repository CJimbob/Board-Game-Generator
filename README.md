# 王冠之城

一款支持 2–6 人在线房间的秘密选角、城市建造网页桌游。可以邀请朋友加入，也可以添加电脑对手立即开始。

## 已实现

- 四位房间码、跨设备加入和自动同步
- 8 个基础角色的秘密轮选与按编号行动
- 刺客、盗贼、魔术师、国王、主教、商人、建筑师和军阀能力
- 金币、抽牌、手牌、城区建造与军阀破坏
- 电脑玩家自动选角和行动
- 七城区终局、颜色奖励、完成奖励和最终排名
- 刷新后自动回到当前房间

## 本地运行

```bash
npm install
npm run dev
```

访问 `http://localhost:3000`。

## 验证

```bash
npm test
```

房间状态存储在 Cloudflare D1 中；部署配置位于 `.openai/hosting.json`。
